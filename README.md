# Bebek Takip

Bez ve beslenme takibi için ana ekrana eklenebilir web uygulaması (PWA).

- Arayüz: bu depo, GitHub Pages üzerinden yayınlanır.
- Veri: Google Apps Script veri servisi + Google Sheets (bu depoda değil).
- Giriş: "Google ile oturum aç"; sadece beyaz listedeki hesaplar kullanabilir.

`config.js` içinde `API_URL` (Apps Script `/exec` adresi) ve `CLIENT_ID` (Google OAuth istemci kimliği) doldurulmalıdır.
